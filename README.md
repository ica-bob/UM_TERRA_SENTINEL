# UM_TERRA_SENTINEL
UM_TERRA_SENTINEL - UM_Terra Sentinel is a browser-based live Earth intelligence console. It shows natural hazards and space and weather conditions on an interactive 3D globe. It is a design-only upgrade of your TerraView Sphere site, and it carries your copyright (© 2026 Utsav Mukherjee)

For the first GitHub Pages deployment, add a repository Actions secret named `PAGES_TOKEN` containing a token with Pages write access. The workflow uses it to enable Pages. Once Pages is enabled, the secret can be removed; normal deployments use `GITHUB_TOKEN`. Never commit the token value.
